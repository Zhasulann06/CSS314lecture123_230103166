# CS482 Parallel Computing Lab Practicum

On the measured Intel Core i5-11400H (6 physical cores, 12 threads), the 128 MiB stride benchmark rose from 1.08 ns per element at stride 1 to 3.68 ns at stride 8 as accesses stopped reusing most of each 64-byte cache line; changing matrix multiplication from i-j-k to i-k-j improved median runtime by 1.53x with a maximum numerical difference below 1e-12. At eight processes, adjacent shared counters took 2.95 s versus 2.08 s with 64-byte padding, while local privatization avoided repeated shared writes; Karp-Flatt values for these runs are recorded as specified, although each process performs K increments so total work grows with P and those values are not a fixed-work serial fraction. The five-point stencil reached 2.12x strong-scaling speedup at six processes; weak scaling completed 6.01x as many cell updates in 1.78x the time, for 3.38x scaled throughput. Its theoretical 0.104-0.313 FLOP/byte intensity suggests a bandwidth-sensitive optimized kernel, but the measured NumPy implementation also includes array temporaries and process startup.
